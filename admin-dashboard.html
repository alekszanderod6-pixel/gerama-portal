How uploading works — no GitHub needed When you upload a file here, it goes directly to Supabase Storage (a cloud database). The file gets a public URL and is saved to the database — students can access it immediately, no deploy or GitHub push required.

The "path" you may have seen is just the folder structure inside Supabase Storage (e.g. l100/semester-1/applied-electricity/slides/handout.pdf). You don't need to worry about it — it's built automatically from the fields you fill in below.

⚠️ One-time setup required: Go to your Supabase Dashboard → Storage → New Bucket → Name: gerama-materials → Toggle Public ON → Save. Then go to Settings → Test Supabase Connection to confirm it's ready.

Software uploads — two ways Option 1 — File upload: Upload a setup file (.exe, .zip, .msi) directly to Supabase Storage. Good for small setups under 50MB.
