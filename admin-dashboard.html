Import Quiz Scores from External Platform

Finished a quiz on Testmoz, Google Forms or any platform? Import scores in 2 steps: download CSV from the platform, then upload it here.

📋 How to export from Testmoz: Open your quiz → Results tab → Download CSV
📋 How to export from Google Forms: Open responses → Spreadsheet icon → File → Download → CSV
Format needed: A column with student email and a column with their score (any column order is fine — system auto-detects)
